# Calculator Using C++ and Qt

A simple desktop calculator application developed using C++ and the Qt Widgets library.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal calculations
- Clear button
- Basic calculator interface

## Technologies Used

- C++
- Qt 6
- Qt Widgets
- CMake

## Project Files

- `main.cpp` - Entry point of the application
- `Calculator.cpp` - Calculator implementation
- `Calculator.h` - Calculator class declaration
- `Calculator.ui` - Qt Designer user interface
- `CMakeLists.txt` - CMake project configuration

## How to Run

Open the project using Qt Creator with a Qt 6 kit and build the project using CMake.
